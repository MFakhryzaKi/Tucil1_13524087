## Menjalankan Program
1. Pastikan anda berada di direktori utama (root), kemudian jalankan perintah ini pada terminal untuk melakukan kompilasi program
```bash
g++ .\src\main.cpp -o bin/main
```

2. Setlah itu, jalankan file executable yang sudah terkompilasi dengan perintah berikut
```bash
.\bin\main.exe
```

Ketika program dijalankan, program akan menampilkan
```bash
Masukkan nama file yang ingin diuji:
```
kemudian meminta input dari pengguna. Masukkan nama file yang ingin diselesaikan (beserta ekstensinya). Pastikan file yang ingin diselesaikan terletak pada folder test.

3. Setelah program selesai dijalankan, apabila terdapat solusi dari file input yang diberikan, program akan memberi pilihan sebagai berikut
```bash
Apakah anda ingin menyimpan hasil? (Y/N)
```
Apabila pengguna memilih "Y", hasil penyelesaian bisa disimpan menjadi file .txt yang akan tersimpan pada folder output.
